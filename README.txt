XC Op Report Generator PWA

Includes:
- Updated home-screen app icon reading “OP REPORT GENERATOR”
- PWA manifest with 192x192 and 512x512 PNG icons
- iOS apple-touch-icon metadata
- Service worker cache for offline use, including the icons
- Existing incident form, statement generation, draft saving and archive functionality

Install:
1. Host the extracted files on an HTTPS web host.
2. iPhone/iPad: open in Safari, Share -> Add to Home Screen.
3. Android: open in Chrome, menu -> Install app / Add to Home screen.

Local report data stays in the browser on that device. Review every generated report for factual accuracy before submission.
